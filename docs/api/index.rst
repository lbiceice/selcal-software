SelCal documentation
====================

SelCal is a pre-release Python core for selection-aware surrogate calibration.
The current implementation demonstrates the M0--M2 software contracts. It does
not yet establish scientific error control, comparative impact, independent
reuse, or SoftwareX submission readiness.
